https://github.com/Vivi-Snowy   |   Support me: https://ko-fi.com/vivienne38

1. Copy everything in this folder into your "Arma 2 Operation Arrowhead" game folder
   (AFTER the DayZ Epoch 1.0.7.1 client and server files). Say Yes to replace files.
2. Double-click INSTALL.bat and click Yes when Windows asks.
3. In your Steam library start "1 START SERVER", wait 1-2 minutes, then start "2 PLAY".

Full guide, download links and troubleshooting: https://github.com/Vivi-Snowy/Vivs-Epoch
Feature lists: docs\CHERNARUS_FEATURES.txt and docs\LINGOR_FEATURES.txt
